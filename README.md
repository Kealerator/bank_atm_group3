# Ryhmä 3 opiskelijoiden pankkiautomaatti-projekti

Johdatus
 - Projektin tarkoituksena on luoda pankkiautomaatti.
 - Qt-sovellus kommunikoi REST APIn kanssa http-protokollan avulla.
 - REST API hoitaa kommunikoinnin tietokannan kanssa.

Työkalut
 - Github
 - Visual Studio Code
 - Uniform Server Zero
 - Postman
 - QT-Creator
 - MySQL Workbench

Sovelluksen arkitehtuuri
 -Tietokanta MySQL
 -REST API (Node.js/Express.js)
 -Pankkiautomaattisovelluksen (Qt työpöytäsovellus, jossa käytetään Qt Network moduulia)
